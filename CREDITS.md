# Credits

## Pretext

This plugin is built on **[Pretext](https://github.com/chenglou/pretext)**, created by **[Cheng Lou](https://github.com/chenglou)** and developed with the Pretext contributors. The moving-shapes interaction was inspired by Pretext's [editorial-engine demo](https://chenglou.me/pretext/editorial-engine/).

The actual `@chenglou/pretext` **1.0.0** package is bundled locally, without modifying its source. Pretext supplies text segmentation, measurement preparation and line-breaking APIs. This plugin supplies Figma-native font measurements, obstacle geometry, editable Figma output, document lifecycle handling and the control panel.
